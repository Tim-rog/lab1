Учебный проект: калькулятор выражений и конвертер единиц измерения.

## Возможности

- Вычисление математических выражений (скобки, приоритет операций)
- Конвертация единиц (в том числе температуры)
- Запуск через CLI: `python -m toolkit ...`

# Использование
- pyton -m toolkit calc "ex" -- возвращает резульатта работы сортировчной станции Дейтла
- pyton -m toolkit calc= "ex" -- считает и выдаёт ответ
- pyton -m toolkit сonvert "ex" -- конвертирует

## Условия синтаксиса
    calc принимает выражения в том числе с буквами, если эти буквы означают единицы измерения, может привести к одному виду
    и выдать ответ. Например: 100g - 1kg = -900g
    Из-за этого калькулятор может галюцинировать, если вводить недопстимые символы, ошибки не будет, однако овтет не будет осмысленным
